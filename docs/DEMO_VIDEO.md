# 90-second demo video

This is the recording plan for a short, honest product demo aimed at developers, funders and independent media creators. Record it from the working application in a 16:9 browser window. Keep the host on camera only if that makes the recording easier; the product should remain the focus.

## Before recording

- Use headphones so the AI caller audio is clean.
- Prepare one approved caller with a visually clear portrait and a simple opinion or dilemma.
- Create a show with that caller first in the running order.
- Open the show workspace, Host Studio and broadcast output in separate tabs.
- Test the caller privately once.
- Hide API keys, private URLs, browser bookmarks and unrelated notifications.
- Reset the show so the caller is ready and the broadcast display is clean.
- Record system audio as well as the microphone.

## The unscripted exchange

Keep this deliberately simple so viewers can hear that the interaction is live.

**Host:** “Morning, Sam. You said your neighbours have taken this too far. What actually happened?”

Let the caller respond, then interrupt naturally:

**Host:** “Hang on—when you say every morning, do you genuinely mean seven days a week?”

End after the second answer. Do not try to demonstrate every feature in one conversation.

## Recording notes

- Aim for 80–100 seconds; clarity is more important than hitting exactly 90.
- Use direct cuts rather than animated transitions.
- Keep the browser zoom large enough for labels to be readable.
- Do not add background music over the live conversation.
- Caption the final edit.
- Avoid claims such as “the first” or “revolutionary”; let the workflow demonstrate the novelty.
- Export at 1920×1080, H.264, with clear stereo audio.
- Upload to YouTube as unlisted/public or attach it to a GitHub release, then add the final link near the top of the README.
